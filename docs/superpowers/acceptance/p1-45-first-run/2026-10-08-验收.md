## 四、测量方法账（这一轮踩到的坑，写下来免得下轮重犯）

1. **`Contains(body, "")` 恒真**：把"查 map"改成"查页面"时，我把唯一守着"键不许从白名单消失"的断言删了，而新断言在键消失时正好打空串——**改强断言的那一刀最容易顺手删掉旧守卫**。先把"这一刀会删掉哪些断言"列出来，再为每条新断言配一把对应的破坏（`sab7.out` 复现 → `sab6.out` N9/N10 收口）。
2. **注释里的数会漂**：`taken` 的读数本机三跑的 min 是 23、26、29，写死任何一个都是给下一轮留谎；预算读数六条整体漂了 +129/+60 而线没破，只有整组重量才看得见。
3. **`resize_page` 说不了话**：它成功执行但不回读数，窄屏要用 `emulate viewport`（390 那档就是这么来的），并且每次都要 `evaluate_script` 回读 `innerWidth` 才算证明。
4. **Git Bash 会把 docker 的路径参数改写**：`-v "$PWD":/src` 变成 `C:/Program Files/Git/src`，容器直接起不来；要 `MSYS_NO_PATHCONV=1` + 显式 `D:/...` 源路径。
5. **PowerShell 的中文回显在 Bash 里是二进制**：判定要看落盘文件，不要扫 stdout（`Out-File -Encoding utf8` 之后用 Read）。
6. **探针自己会写错**：`NextProfileID` 返回一个值，探针里写 `_, _ =` 直接编译失败——`build_err` 与"红"必须分开统计，否则一条坏探针会被当成一条证人（这轮 K1/K2 第一次跑就是这种情况，改对之后才红在该红的地方）。
